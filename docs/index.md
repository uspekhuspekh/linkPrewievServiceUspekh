## Как читать документацию

Документы описывают то, что подтверждается текущим исходным кодом. Комментарии в коде могут быть устаревшими; при расхождении приоритет имеет фактическая реализация.

Исторический контекст предыдущих обсуждений использован для объяснения назначения компонентов, но не считается доказательством их текущего поведения.

## Границы текущей версии

- Документация не предполагает, что проект уже исправлен по результатам аудита.
- Найденные проблемы описаны отдельно и не исправлялись.
- `utils/logger.js` рассматривается как целевой централизованный логгер проекта. В текущем состоянии часть модулей ещё использует `utils/debugHandler.js`; унификация логирования является отдельной будущей задачей.
- Значения API-ключей и другие секреты намеренно не приводятся.
